# Tripo-Blander-.GLB
Tripo → Blender
Download Tripo Studio 3D models as Blender-compatible GLB files with Meshopt decompression.
"Tripo → Blender" is a browser extension that helps download 3D models from Tripo Studio in GLB format for use in Blender.

🇬🇧 English
Installation:
1. Download the project files from this repository:
• Click Code → Download ZIP.
• Extract the downloaded archive to a folder.

1. Open browser and navigate to *browser name*://extensions. Or open "Manage extensions"
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the extracted extension folder containing manifest.json.

How to use
1. Open Tripo Studio and navigate to the 3D model you want to download.
2. Wait until the model page has fully loaded.
3. Click the "Tripo → Blender" extension icon in your browser toolbar.
4. Follow the extension’s prompts and wait for the download to finish.
5. Import the downloaded .glb file into Blender.
Notes
• Make sure the model page is fully loaded before using the extension.
• Keep all extension files together in the same folder.
• If you move or delete the extension folder, Chrome may no longer be able to load the extension.
• This extension is an independent community project and is not affiliated with or endorsed by Tripo Studio or Blender.
Важно
