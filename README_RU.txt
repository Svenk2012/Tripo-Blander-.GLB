Tripo Blender

Установка:
1. Распакуйте архив в отдельную папку.
2. Откройте *ваш браузер*://extensions (или страницу расширений совместимого Chromium-браузера).
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Выберите эту распакованную папку.

Использование:
1. Откройте страницу модели на https://studio.tripo3d.ai/ и дождитесь загрузки 3D-превью.
2. Нажмите значок TB и кнопку «Скачать модель .GLB».
3. Расширение скачает GLB и локально распакует Meshopt, если он используется.

Как пользоваться
1. Откройте страницу модели на https://studio.tripo3d.ai/ и дождитесь загрузки 3D-превью.
2. Нажмите значок расширения "Tripo Blender" и кнопку «Скачать модель .GLB».
3. Следуйте подсказкам расширения и дождитесь завершения загрузки.
4. Импортируйте скачанный файл .glb в Blender.
Важно
• Перед использованием обязательно дождитесь полной загрузки страницы модели.
• Не удаляйте отдельные файлы расширения и не переносите их в другие папки по отдельности.
• Если переместить или удалить папку расширения, Chrome может перестать его загружать.
• Для обновления расширения замените файлы новой версией и нажмите кнопку обновления на странице chrome://extensions.
